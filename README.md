\# 🌍 Global Health \& Life Expectancy Dashboard



An interactive data visualization dashboard built with \*\*Python, Pandas, Plotly, and Dash\*\* to explore global health and life expectancy data across different countries and regions.



The dashboard transforms raw health and economic data into interactive visual insights, helping users understand relationships between \*\*life expectancy, GDP, population, countries, regions, and time\*\*.



\---



\## 📊 Project Overview



This project focuses on analyzing global health indicators and presenting them through an interactive web dashboard.



Users can select a \*\*region\*\* from the dropdown menu, and all visualizations update dynamically to display insights specific to that region.



\### Key Questions



\* 🌍 How does life expectancy vary between countries?

\* 💰 Is GDP per capita related to life expectancy?

\* 👥 How does population size compare across countries?

\* 📈 How has life expectancy changed over time?

\* 📊 What is the distribution of life expectancy within each region?

\* 🔎 How do countries within the same region compare with each other?

\## 📈 Dashboard Visualizations



The dashboard includes \*\*10 interactive charts\*\*:



| Visualization          | Purpose                                                     |

| ---------------------- | ----------------------------------------------------------- |

| 📊 Bar Chart           | Compare average life expectancy across countries            |

| 🔵 Scatter Plot        | Analyze the relationship between GDP and life expectancy    |

| 🫧 Bubble Chart        | Compare GDP, life expectancy, and population simultaneously |

| 📉 Histogram           | Explore the distribution of life expectancy                 |

| 📦 Box Plot            | Identify spread and potential outliers                      |

| 🎻 Violin Plot         | Analyze the distribution and density of life expectancy     |

| 📈 Line Chart          | Track life expectancy trends over time                      |

| 🌊 Area Chart          | Visualize changes in life expectancy over time              |

| 📚 Stacked Bar Chart   | Compare countries across different years                    |

| 📊 Clustered Bar Chart | Compare country-level life expectancy by year               |

\## ✨ Interactive Features



\### 🌍 Region Filter



The dashboard includes an interactive dropdown that allows users to select a region.



Once a region is selected:



\* All charts are automatically updated.

\* Country-level comparisons are recalculated.

\* Time-based trends are refreshed.

\* Regional health patterns become easier to explore.

\## 🚀 Getting Started



\### 1️⃣ Clone the Repository



```bash

git clone https://github.com/your-username/global-health-life-expectancy-dashboard.git

```



\### 2️⃣ Navigate to the Project



```bash

cd global-health-life-expectancy-dashboard

```



\### 3️⃣ Install Dependencies



```bash

```



Or install the required libraries manually:



```bash

```



\### 4️⃣ Run the Dashboard



```bash

```



The application will start locally.

