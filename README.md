# 🌍 Global Health & Life Expectancy Dashboard

An interactive data visualization dashboard built with **Python, Pandas, Plotly, and Dash**.

## 📊 Project Overview

This project analyzes global health and socioeconomic data to explore:

- 🌍 Life expectancy across countries
- 💰 GDP per capita
- 👥 Population
- 📈 Life expectancy trends over time
- 🔎 Regional comparisons

## 🛠️ Technologies Used

- Python
- Pandas
- Plotly
- Dash

## 📈 Dashboard Visualizations

The dashboard includes:

- Bar Chart
- Scatter Plot
- Bubble Chart
- Histogram
- Box Plot
- Violin Plot
- Line Chart
- Area Chart
- Stacked Bar Chart
- Clustered Bar Chart

## ✨ Interactive Features

Users can select a **region** from the dropdown menu, and all charts update automatically.
